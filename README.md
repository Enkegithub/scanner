This scanner web app is used to scan the QR code that is generated from our Google Sheet registration data.

Each team receives a unique QR code. When the QR code is scanned, the web app verifies the registration ID from the Google Sheet.

If the registration ID is valid and the team has not entered before, the system automatically updates the sheet and marks the team as PRESENT, along with the entry time.

If the same QR code is scanned again, it shows a duplicate entry, so re‑entry is prevented.

This system is mainly used for college events to make entry verification fast, secure, and paper‑free.
